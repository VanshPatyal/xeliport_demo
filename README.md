# Xeliport

Global trade and supply chain control tower dashboard prototype.

**Repository:** [VanshPatyal/xeliport_demo](https://github.com/VanshPatyal/xeliport_demo)

**Live demo:** [Open Xeliport](https://vanshpatyal.github.io/xeliport_demo/)

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Create a production build with `pnpm build` and run it with `pnpm start`.
